System Operational Assurance Guide

Shree Dedhgaun Secondary School System Setup: Connect this administrative PC via 3.5mm audio jack to your school amplifier / PA system speakers.
Automatic Operation & Offline Bell Caching
  1. Automatic Startup: The Bell Scheduler starts automatically in AUTOMATION ACTIVE mode as soon as the browser opens.
  2. 10 Default Bell MP3s: On first internet connection, all 10 period, tiffin, and start/end bell MP3 tracks are downloaded into permanent IndexedDB Blob storage for 100% offline playback.
  3. Power Configuration: Configure Windows / OS power settings to "Never Sleep" while plugged in.
  4. Managed Chrome / Edge Kiosk Autoplay Policy: Standard browsers restrict unclicked background audio unless permitted. On dedicated school PA computers, launch Chrome/Edge with --autoplay-policy=no-user-gesture-required or allow Sound in Site Settings (chrome://settings/content/sound) for completely unattended startup.
Important Browser & Network Notes
  • Smart Audio Mapping: Period 1–8, Tiffin, and School Start/Dismissal events automatically play their mapped default MP3 from IndexedDB unless overridden by a custom track.
  • Synthesized Fallback: If a default MP3 is manually deleted or offline before initial caching, the engine seamlessly rings the synthesized Nepali Iron School Bell on AudioContext.currentTime.
  • URL Audio Import & CORS: Direct audio URLs (such as GitHub raw links) are verified by binary header inspection. Remote servers that block CORS require same-origin hosting or local file upload.
